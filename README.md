# Results Analyser V4

Browser-based Streamlit app.

## Run
pip install -r requirements.txt
streamlit run app.py

## Inputs
- Direct PDF URL
- PDF upload
- Q1/Q2/Q3/Q4
- AUTO / Consolidated / Standalone
- Optional OCR

## Output
Revenue, EBITDA, margins and consolidated/standalone net profit in the agreed four-line format, plus calculation details and diagnostics.
